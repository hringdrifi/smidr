# Smiðr でできること

Smiðr は、自作キーボードの設計と調整で散らばりやすい作業を、ひとつのプロジェクトとして扱います。

## 設計

キーの物理配置、サイズ、回転、レイアウトオプションを編集できます。一般的な ANSI / ISO / JIS 配列だけでなく、分割キーボードや親指クラスタのような配置も扱います。

## 配線情報

各キーに row / col を設定し、見た目の並びとマトリックスの対応を確認できます。

## キーマップ

レイヤーごとのキーコード、透過キー、レイヤータップ、モッドタップなどを編集できます。

## 実機リマップ

VIA / Vial または ZMK Studio 互換のキーボードに接続し、読み込んだキーマップを編集するリマップモードがあります。
