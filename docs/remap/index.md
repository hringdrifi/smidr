# リマップモード

リマップモードでは、VIA / Vial または ZMK Studio 互換のキーボードに接続し、現在のキーマップを読み込んで編集します。手元のキーボードのキー割り当てを変えたい一般ユーザーは、まずこのモードを使います。

対応キーボードであれば、ファームウェアを書き換えずにキー割り当てを変更できます。接続方式や保存方法はキーボード側の対応状況によって変わります。

## 接続する

キーボードを PC に接続してから、画面上部の `接続` を押します。接続メニューでは、キーボードやファームウェアが対応している方式を選びます。

- `WebHID`: VIA / Vial 互換キーボードで使うことが多い接続方式です。
- `WebSerial`: ZMK Studio 互換キーボードを USB / COM ポート経由で編集する場合に使います。

ZMK Studio 互換キーボードを無線で編集する場合は、ブラウザ版ではなく Smiðr のネイティブアプリを使ってください。特に Windows 版 Chrome では、ブラウザ版 Smiðr からの BLE 編集には対応していません。

ブラウザからデバイス選択ダイアログが表示されたら、編集したいキーボードを選びます。接続できない場合は、別のアプリがキーボードを開いていないか、対応ファームウェアが書き込まれているかを確認します。

## 読み込み

接続に成功すると、Smiðr はキーボードを編集するために必要な情報を読み込みます。読み込む情報には、キーの位置や形を表す定義情報と、現在デバイスに入っているキーマップがあります。

どこから定義情報を取得できるかは、接続先の種類によって変わります。

### Vial 互換キーボード

Vial 互換キーボードでは、デバイス側にレイアウト定義が含まれているため、接続後にキーボードから定義情報とキーマップを読み込みます。

Smiðr は取得した定義情報を使って、実機の物理レイアウトに合わせた画面を表示します。別途プロジェクトを開かなくても、デバイスから得られる情報をもとに編集を始められます。

### ZMK Studio 互換キーボード

ZMK Studio 互換キーボードでも、デバイス側からキー位置やキーマップ編集に必要な情報を読み込みます。

ただし、ZMK Studio ではデバイス側のロック状態や保存状態により、読み込みや編集が制限されることがあります。ロック解除や再接続が必要な場合は、画面の表示に従って操作します。

### VIA 互換キーボード

VIA 互換キーボードでは、デバイスから現在のキーマップを読み込みます。一方で、物理レイアウトなどの定義情報は、Smiðr に保存されているプロジェクトから取得します。

そのため、VIA 互換キーボードをリマップする場合は、対象キーボードに対応する Smiðr プロジェクトが準備されている必要があります。Smiðr はプロジェクト内の定義情報と、デバイスから読み込んだキーマップを組み合わせて編集します。

プロジェクトの定義情報と接続したキーボードの定義がずれていると、画面上のキー位置と実機のキーが対応しないことがあります。VIA で編集する場合は、接続するキーボードに合ったプロジェクトを使ってください。

## キーを変更する

キー割り当てを変更するには、キャンバス上のキーを選択し、下部のキーパレットから割り当てたいキーコードを選びます。基本キー、ISO/JIS キー、レイヤー操作、メディアキー、マクロ、特殊キーなどをタブから切り替えて選択できます。

より細かい動作を設定する場合は、`キーマップ設定` を使います。レイヤータップ、モッドタップ、レイヤー一時切り替え、レイヤートグルなど、単純なキー入力以外のアクションを設定できます。

アクションタイプやキーコードの種類について詳しくは、[アクション / キーコード](/reference/actions) を参照してください。

## レイヤーを編集する

画面上部またはレイヤー操作部分で、編集するレイヤーを切り替えます。レイヤー 0 は通常の入力に使う基本レイヤーです。レイヤー 1 以降には、記号、数字、ファンクションキー、メディア操作などを割り当てることがよくあります。

レイヤーキーを設定すると、押している間だけ別レイヤーへ移動したり、タップとホールドで違う動作をさせたりできます。親指キーにレイヤータップを割り当てると、小さいキーボードでも多くのキーを扱いやすくなります。

## 変更の反映

リマップモードでキー割り当てを変更すると、変更はすぐに接続中のデバイスへ反映されます。別途「保存」ボタンを押してから反映する流れではありません。

ただし、キーボードがロックされている場合や、接続状態に問題がある場合は、変更を書き込めません。画面にロック解除、再接続、同期などの案内が表示された場合は、その表示に従って操作します。

変更後は、実際にキーを押して期待した動作になっているか確認してください。特にレイヤーキーやモッドタップは、短押しと長押しの動作を確認すると安心です。

## バックアップ

リマップ前後の状態を残したい場合は、バックアップを書き出します。バックアップを保存しておくと、あとで同じキーマップへ戻したいときや、別の環境で設定を復元したいときに使えます。

大きく変更する前、レイヤーを作り直す前、マクロや特殊キーを多く変更する前には、現在の状態をバックアップしておくと安全です。

## ロック解除

一部のキーボードでは、キーマップを書き換える前にロック解除が必要です。画面にロック解除の案内が表示された場合は、指定されたキーの組み合わせを実機で押すなど、デバイス側の手順に従います。

ロック解除は、信頼できる PC で行ってください。解除後の状態や再ロックの方法は、キーボードやファームウェアによって異なります。
