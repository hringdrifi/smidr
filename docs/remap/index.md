# リマップモード

リマップモードは、VIA、Vial、ZMK Studio対応キーボードから現在の設定を読み込み、ファームウェアを書き換えずに編集する画面です。プロジェクトホームの「キーボードを接続」またはヘッダーの「リマップ」から開きます。

<figure>
  <img :src="withBase('/assets/smidr-remap-connect.png')" alt="リマップモードの接続メニュー">
  <figcaption>利用するプロトコルと接続方式を選びます。</figcaption>
</figure>

## 接続方式

| 対象 | 接続 | 定義情報 |
| --- | --- | --- |
| VIA | WebHID | 対象キーボードに対応するSmiðrプロジェクトのレイアウトを利用します。 |
| Vial | WebHID | デバイスからレイアウト定義とキーマップを取得します。 |
| ZMK Studio（USB） | Web Serial | デバイスのメタデータ、physical layout、キーマップを取得します。 |
| ZMK Studio（無線） | デスクトップ版のBLE | ブラウザー版ではなくSmiðrデスクトップ版を使用します。 |

接続できない場合は、別の設定アプリがデバイスを開いていないか、対応ファームウェアが書き込まれているかを確認してください。

## VIAで必要なプロジェクト

VIAプロトコルは実機から物理レイアウトを取得しないため、VID/PIDが一致する保存済みSmiðrプロジェクトを定義として利用します。プロジェクトのマトリクス位置と実機が一致しない場合、画面上のキーと書き込み先がずれます。

VialとZMK Studioは接続時にデバイス側の定義を読み取るため、通常は設計プロジェクトを事前に開く必要がありません。

## キー割り当て

<figure>
  <img :src="withBase('/assets/smidr-remap-connected.png')" alt="接続済みのリマップ画面">
  <figcaption>キャンバスでキーを選び、対象別パレットまたは詳細設定から変更します。</figcaption>
</figure>

変更は接続中の機器へ直接書き込まれます。パレットには接続中プロトコルで表現できるキーだけが表示されます。Macro、Combo、Tap Dance、ライティングなどはデバイスが公開したケイパビリティに応じて有効または無効になります。

対応範囲と制限は[アクション / キーコード・ファームウェア対応表](/reference/actions)を参照してください。

## ZMK Studioのロックと保存

ZMK Studioがロックされている場合は、キーマップ上のStudio Unlock動作を実機で押して解除します。変更後、デバイスが保存操作を要求する場合は画面の保存操作を実行してください。新しいMacroやTap Danceなど、デバイスに存在しないbehavior定義をリマップ画面から追加することはできません。

## バックアップ

接続後のツールバーから現在のリマップ状態を `.smidr` として保存し、後から復元できます。大きな変更やレイヤー構成の編集前に保存しておくと戻しやすくなります。復元時は対象デバイスへ順番に書き込み、最後に再同期します。
