# リマップモード

リマップモードでは、VIA / Vial または ZMK Studio 互換のキーボードに接続し、現在のキーマップを読み込んで編集します。手元のキーボードのキー割り当てを変えたい一般ユーザーは、まずこのモードを使います。

対応キーボードであれば、ファームウェアを書き換えずにキー割り当てを変更できます。接続方式や保存方法はキーボード側の対応状況によって変わります。

## 接続する

キーボードを PC に接続してから、画面上部の `接続` を押します。接続メニューでは、キーボードやファームウェアが対応している方式を選びます。

- `WebHID`: VIA / Vial 互換キーボードで使うことが多い接続方式です。
- `WebSerial`: ZMK Studio 互換キーボードや、シリアル接続で編集するキーボードで使います。
- その他の方式: ブラウザや OS、キーボード側の対応状況によって利用できる接続方式が変わります。

ブラウザからデバイス選択ダイアログが表示されたら、編集したいキーボードを選びます。接続できない場合は、別のアプリがキーボードを開いていないか、対応ファームウェアが書き込まれているかを確認します。

## 読み込み

接続に成功すると、Smiðr はキーボードからレイアウト情報やキーマップを読み込みます。VIA / Vial の定義情報を取得できる場合は、実機の物理レイアウトに合わせた画面で編集できます。

ZMK Studio 互換キーボードでは、デバイス側の状態に応じて読み込みや編集が制限されることがあります。ロック状態、保存状態、接続方式などは画面の表示に従って確認します。

## キーを変更する

キー割り当てを変更するには、キャンバス上のキーを選択し、下部のキーパレットから割り当てたいキーコードを選びます。基本キー、ISO/JIS キー、レイヤー操作、メディアキー、マクロ、特殊キーなどをタブから切り替えて選択できます。

より細かい動作を設定する場合は、`キーマップ設定` を使います。レイヤータップ、モッドタップ、レイヤー一時切り替え、レイヤートグル、Any など、単純なキー入力以外のアクションを設定できます。

アクションタイプやキーコードの種類について詳しくは、[アクション / キーコード](/reference/actions) を参照してください。

## レイヤーを編集する

画面上部またはレイヤー操作部分で、編集するレイヤーを切り替えます。レイヤー 0 は通常の入力に使う基本レイヤーです。レイヤー 1 以降には、記号、数字、ファンクションキー、メディア操作などを割り当てることがよくあります。

レイヤーキーを設定すると、押している間だけ別レイヤーへ移動したり、タップとホールドで違う動作をさせたりできます。親指キーにレイヤータップを割り当てると、小さいキーボードでも多くのキーを扱いやすくなります。

## 保存と同期

リマップモードでの変更がいつデバイスへ反映されるかは、接続しているファームウェアや通信方式によって異なります。画面上に保存、同期、書き込み、ロック解除などの操作が表示される場合は、その表示に従って操作します。

VIA / Vial 互換キーボードでは、変更が実機側へ書き込まれる形で扱われます。ZMK Studio 互換キーボードでは、デバイス側の保存状態やロック状態により、追加の操作が必要になることがあります。

変更後は、実際にキーを押して期待した動作になっているか確認してください。特にレイヤーキー、モッドタップ、Any などは、短押しと長押しの動作を確認すると安心です。

## バックアップ

リマップ前後の状態を残したい場合は、バックアップを書き出します。バックアップを保存しておくと、あとで同じキーマップへ戻したいときや、別の環境で設定を復元したいときに使えます。

大きく変更する前、レイヤーを作り直す前、Any やマクロを多く使う前には、現在の状態をバックアップしておくと安全です。

## ロック解除

一部のキーボードでは、キーマップを書き換える前にロック解除が必要です。画面にロック解除の案内が表示された場合は、指定されたキーの組み合わせを実機で押すなど、デバイス側の手順に従います。

ロック解除は、信頼できる PC で行ってください。解除後の状態や再ロックの方法は、キーボードやファームウェアによって異なります。

## 接続済み画面の画像

接続済み画面のスクリーンショットは実機環境に依存します。差し替え用の画像を追加する場合は、Vial または ZMK Studio 対応キーボードを接続した状態で撮影します。
