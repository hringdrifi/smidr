# インポート / エクスポート

Smiðrでは、プロジェクトの保存、外部レイアウトの読み込み、基板データ、ファームウェアソースを目的別の場所から扱います。

## `.smidr` プロジェクト

プロジェクトホームの「プロジェクトをインポート」またはヘッダーのプロジェクトメニューから `.smidr` を開けます。ヘッダーの出力メニューから現在のプロジェクトを `.smidr` として保存できます。

現在の保存形式は `schemaVersion: "0.5"` です。旧形式は読み込み時に変換され、次の書き出しから0.5形式になります。

## レイアウトJSON

プロジェクトを開いた状態でヘッダーの読み込みボタンから、KLE、VIA、Vial、QMK互換JSONを読み込めます。現在のレイアウトを置き換えるため、既にキーがある場合は確認が表示されます。

ヘッダーの出力メニューにはKLE JSONとキャンバスPNGがあります。ファームウェアやKiCadの出力はここには含まれません。

## ファームウェアソース

ファームウェア工程で対象を選択し、最後の「{ファーム名}出力」を開きます。Smiðrはボード/MCU、配線、ピン、キー割り当てなどを検証してから、QMK/VIA、Vial、ZMK、RMK用のZIPを生成します。

ZMKでは標準出力とZMK Studio対応出力を選べます。Studio対応出力にはphysical layoutとStudio用ビルド設定が含まれ、キーマップ内には操作可能なStudio Unlockキーが必要です。

出力されるアクションとキーの差は[アクション / キーコード・ファームウェア対応表](/reference/actions)を参照してください。

## KiCadデータ

ハードウェア工程の「基板出力」から生成します。フットプリントやLED位置に関する警告を確認してからZIPを保存してください。ファームウェアソースとは独立した出力です。

## リマップのバックアップ

実機へ接続すると、リマップ用ツールバーにバックアップの読み込みと保存が表示されます。これは接続中デバイスのキーマップを退避・復元するための `.smidr` であり、設計プロジェクトの保存操作とは用途が異なります。
