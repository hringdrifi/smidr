# インポート / エクスポート

Smiðr は、外部ツールやファームウェアへデータを受け渡すためのインポート / エクスポート機能を持っています。

## インポート

KLE 互換 JSON や Smiðr のバックアップファイルからプロジェクトを読み込めます。KLE から読み込んだ場合も、Smiðr 内でマトリクス、キーマップ、ハードウェア設定を追加していけます。

## エクスポート

レイアウト JSON、Smiðr バックアップ、QMK / VIA / Vial / ZMK 向けのファイルを出力します。ソース出力を使う場合は、マトリクスとハードウェア設定を先に確認してください。
