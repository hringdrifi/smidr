# はじめに

Smiðrは、カスタムキーボードの物理設計からファームウェア出力までを1つのプロジェクトで扱い、VIA、Vial、ZMK Studio対応キーボードを実機リマップできるツールです。

起動時のプロジェクトホームには「新規プロジェクト」「プロジェクトをインポート」「キーボードを接続」と最近使ったプロジェクトが表示されます。目的に合う入口を選んでください。

## 3つのワークスペース

| ワークスペース | 用途 |
| --- | --- |
| ハードウェア | 基本設定、ピン、レイアウト、マトリクス、KiCad基板データを扱います。 |
| ファームウェア | 対象選択、キーマップ、ライティング、Macro、Combo、Tap Dance、ソース出力を扱います。 |
| リマップ | VIA、Vial、ZMK Studio対応機器へ接続し、実機の設定を読み書きします。 |

ハードウェアとファームウェアでは、左側の工程ナビゲーションが作業順を示します。中央はキャンバス、右側は選択中のキーや機能の編集パネルです。狭い画面では左右のパネルをボタンから開くドロワーとして表示します。

## 設計の基本手順

1. プロジェクトホームで新規プロジェクトを作成します。
2. ハードウェアの「基本設定」で名前、コントローラー、配線方式を確認します。
3. 「ピン設定」でマトリクスと周辺機能のピンを設定します。
4. 「レイアウト」でキーの位置、サイズ、回転、レイアウトオプションを編集します。
5. 「マトリクス」で各キーへrow / colまたはダイレクトピンを割り当てます。
6. ファームウェアへ移動し、QMK/VIA、Vial、ZMK、RMKから対象を選びます。
7. キーマップや対応機能を編集し、最後の「{ファーム名}出力」からソースを書き出します。

どのキーやアクションを出力できるかは[アクション / キーコード・ファームウェア対応表](/reference/actions)で確認できます。

## 保存と復元

編集内容はヘッダーの保存ボタンを押すと正式なプロジェクトとしてブラウザー内へ保存されます。未保存の確定済み変更は復元用ドラフトにも保存され、次に同じプロジェクトを開いたときに復元するか選べます。ヘッダーには「保存中」「保存済み」「未保存」「保存失敗」の状態が表示されます。

プロジェクトを別環境へ移す場合は、出力メニューから `.smidr` ファイルを保存してください。

## 実機をリマップする

  <img :src="withBase('/assets/smidr-remap-connected.png')" alt="接続済みキーボードを編集するリマップ画面">
  <figcaption>リマップでは接続先のプロトコルとケイパビリティに合わせて、利用可能なキーと編集パネルが切り替わります。</figcaption>
</figure>

「キーボードを接続」またはヘッダーの「リマップ」から接続画面を開きます。VIA/VialはWebHID、ZMK StudioはWeb Serial、デスクトップ版ではZMK BLEを利用できます。キー割り当ての変更は接続中の機器へ直接反映されます。
