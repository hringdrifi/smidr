# はじめに

Smiðr は、カスタムキーボードの物理レイアウト、マトリックス、キーマップ、ハードウェア設定をブラウザ上でまとめて扱うためのツールです。KLE 互換のレイアウト編集から、VIA / Vial / ZMK Studio 互換キーボードのリマップまでを、同じ作業の流れで扱えることを目指しています。

## 2つのモード

Smiðr には、キーボードそのものを設計する **設計** モードと、実機に接続してキー割り当てを調整する **リマップ** モードがあります。

まだ設計中のキーボードは設計、手元のキーボードを使いながら調整したいときはリマップを使います。

## 基本の流れ

1. 新規プロジェクトを作成します。
2. プリセットで標準的なレイアウトを読み込むか、既存の KLE / VIA / Vial / QMK JSON を読み込みます。
3. レイアウトでキーの位置、サイズ、回転を整えます。
4. マトリクスで各キーの行・列を割り当てます。
5. キーマップでレイヤーとキーコードを編集します。
6. 上部の「設定」からハードウェア設定を開き、MCU、ピン、ダイオード方向などを設定します。
7. 必要な形式でエクスポートします。
