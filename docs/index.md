# はじめに

Smiðr は、VIA / Vial / ZMK Studio 互換キーボードのリマップと、カスタムキーボードの設計をブラウザ上で扱うためのツールです。手元のキーボードのキー割り当て変更から、KLE 互換のレイアウト編集、マトリクス、キーマップ、ハードウェア設定までを、同じ作業の流れで扱えることを目指しています。

自作キーボードの設計では、キーの物理配置、配線上の row / col、レイヤーごとのキー割り当て、ファームウェア向けの出力が別々の作業になりがちです。Smiðr では、それらをひとつのプロジェクトとして扱い、設計中の情報と実機で調整する情報をつなげて管理します。

## 2つのモード

Smiðr には、実機に接続してキー割り当てを調整する **リマップ** モードと、キーボードそのものを設計する **設計** モードがあります。

手元のキーボードのキー割り当てを変えたい場合は、まず **リマップ** モードを使います。VIA / Vial または ZMK Studio 互換のキーボードに接続し、現在のキーマップを読み込んで編集します。

新しいキーボードを作る、レイアウトやマトリクスを整理する、ファームウェア向けのファイルを書き出す場合は **設計** モードを使います。

## 基本の流れ

### リマップする

1. キーボードを PC に接続します。
2. Smiðr の **リマップ** モードを開きます。
3. `接続` から、キーボードが対応している接続方式を選びます。
4. キーボードからレイアウトとキーマップを読み込みます。
5. 変更したいキーを選び、キーパレットやキーマップ設定で新しいキーコードを割り当てます。
6. 必要に応じてバックアップを書き出します。

### 設計する

1. 新規プロジェクトを作成します。
2. プリセットで標準的なレイアウトを読み込むか、既存の KLE / VIA / Vial / QMK JSON を読み込みます。
3. レイアウトでキーの位置、サイズ、回転を整えます。
4. マトリクスで各キーの行・列を割り当てます。
5. キーマップでレイヤーとキーコードを編集します。
6. 上部の「設定」からハードウェア設定を開き、MCU、ピン、ダイオード方向などを設定します。
7. 用途に合わせて、Smiðr プロジェクトファイル、QMK / VIA / Vial / ZMK 向けのソースファイルを書き出します。
