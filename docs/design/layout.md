# レイアウト編集

レイアウトでは、キーを追加し、ドラッグで位置を調整します。座標は 1u を基準にしており、通常操作では 0.25u 単位にスナップします。

## 選択と移動

- クリック: 1つのキーを選択します。
- Ctrl / Cmd + クリック: 選択を追加または解除します。
- Shift + クリック: 範囲選択します。
- ドラッグ: 選択中のキーをまとめて移動します。
- 回転ハンドルをドラッグ: 選択中のキーを回転します。複数選択時は、フォーカスされているキーのピボットを基準に回転します。
- ピボットハンドルをドラッグ: 回転の基準点を移動します。
- Alt + ドラッグ: スナップを一時的に無効にします。

## キープロパティ

キーを選択すると、画面下部のキープロパティで位置、サイズ、回転角、ピボット位置を数値で編集できます。キャンバス上で大まかに配置してから、キープロパティで座標や角度を整えると、左右対称の配置や細かい親指クラスタの調整がしやすくなります。

### 位置

X と Y は、キーの左上位置を表します。単位は 1u 基準です。キーをドラッグして動かすこともできますが、正確な位置にそろえたい場合は X / Y を直接入力します。

### サイズ

W と H は、キーの横幅と高さを表します。通常のキーは 1u x 1u です。2u キー、縦長キー、親指キーなどを作る場合は、W / H を変更します。

### 回転

回転角は、キーの傾きを表します。キャンバス上の回転ハンドルで調整したあと、数値で角度を整えることができます。左右で同じ角度にしたい場合や、列ごとに一定の角度を付けたい場合に使います。

### ピボット

RX と RY は、回転の基準点です。キーを回転するときは、このピボットを中心に回ります。親指クラスタやカラムスタッガードのように、複数のキーを同じ中心で回転させたい場合は、ピボット位置をそろえてから回転します。

### 複数選択時

複数のキーを選択している場合は、選択中のキーをまとめて移動したり、共通の値を編集したりできます。複数キーの回転では、フォーカスされているキーのピボットが回転の基準になります。

## レイアウトオプション

ISO / ANSI の差分や、分割スペースバー、複数の親指キー構成のように、同じキーボード内で選択式の形を持つ場合はレイアウトオプションを使います。

### グループと選択肢

レイアウトオプションは、グループと選択肢で構成されます。たとえば、Backspace の形を選べるキーボードなら、`Backspace` というグループを作り、その中に `2u` と `Split` のような選択肢を用意します。

キーごとの所属は、キープロパティで設定します。常に表示したいキーはグループを指定せず、選択式にしたいキーだけを該当するグループと選択肢に割り当てます。

### キープロパティで割り当てる

選択中のキーに対して、キープロパティのレイアウトオプション項目からグループを選びます。グループを選ぶと、そのグループにある選択肢を指定できるようになります。

同じ場所に切り替え候補のキーを重ねて置き、それぞれ別の選択肢に割り当てると、レイアウトオプションの切り替えで表示されるキーが変わります。たとえば、2u Backspace のキーを `2u` に、分割 Backspace の2つのキーを `Split` に割り当てます。

### レイアウトオプションパネルで切り替える

右側のレイアウトオプションパネルでは、現在表示する選択肢を切り替えます。ここで選んだ選択肢に一致するキーだけがキャンバス上に表示されます。

設計中は、選択肢を切り替えながら各パターンのキー位置、サイズ、マトリクス情報を確認します。エクスポート時には、グループと選択肢の情報もレイアウト定義に含まれます。

### 使いどころ

- ANSI / ISO / JIS の差分を同じプロジェクトで管理する場合
- 2u キーと分割キーを切り替えたい場合
- 親指クラスタや最下段の候補を複数用意したい場合
- VIA / Vial の layout option と対応するレイアウトを作りたい場合
