# レイアウト編集

「レイアウト」ではキーの追加、位置、サイズ、回転、ピボット、レイアウトオプションを編集します。中央キャンバスで直接操作し、右側のキープロパティで正確な値を入力できます。

<figure>
  <img :src="withBase('/assets/smidr-editor-layout.png')" alt="レイアウト工程でキーを編集する画面">
  <figcaption>複数選択、整列、均等配置、反転コピーを使って左右分割やカラムスタッガード配列を作成できます。</figcaption>
</figure>

## 選択とキャンバス操作

- クリックで単一選択、Ctrl/Cmd+クリックで選択を追加・解除します。
- Shift+クリックで、アンカーからクリック先までを物理的な並び順で範囲選択します。
- Alt+クリックは選択を変えず、フォーカスとアンカーだけを移動します。
- 背景ドラッグで矩形選択、中ボタンドラッグでパン、ホイールでズームします。
- Delete/Backspaceで選択キーを削除し、Escで選択・フォーカス・アンカーを解除します。

## 移動・回転・ピボット

キー本体のドラッグは選択全体を移動します。回転ハンドルはフォーカスキーのピボットを中心に選択全体を回転し、ピボットハンドルは回転中心を移動します。通常は設定中のグリッドと15度単位へスナップし、Altを押している間だけスナップを無効にできます。

座標の表示単位は `u` と `mm` を切り替えられます。内部では `1u = 19.05mm` として保存されます。

## 複数選択と反転コピー

複数選択時のキープロパティでは、上下左右・中央揃えと水平／垂直の均等配置を使用できます。「反転コピー」を開始すると軸指定モードになり、キャンバス上で選んだX座標を軸として左右反転したコピーを作成します。Escまたは操作ボタンの再選択でキャンセルできます。

## レイアウトオプション

ANSI/ISO、分割スペース、複数の親指クラスタなど、同じ基板上で切り替える物理形状をグループと選択肢として管理します。

<figure>
  <img :src="withBase('/assets/smidr-editor-layout-options.png')" alt="レイアウトオプション編集パネル">
  <figcaption>選択中のオプションに属するキーだけを表示しながら編集できます。</figcaption>
</figure>

リストは複数候補から1つ、トグルはOff/Onを選ぶ用途です。常時表示するキーにはグループを設定せず、差分キーだけを該当グループと選択肢へ割り当てます。情報はVIA/Vial互換レイアウトの出力にも使われます。
