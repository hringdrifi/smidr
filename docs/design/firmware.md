# ファームウェア設計ワークフロー

ファームウェア工程では、出力対象を選択し、キーマップや対象固有の機能を設定して、最後にファームウェアソースを出力します。各工程は左側の工程ナビゲーションから移動できます。

## 対象の選択

最初にQMK/VIA、Vial、ZMK、RMKから対象を選択します。選択後は対象に応じて工程が組み替わり、非対応のキーや機能はパレットから除外されます。

## 工程

| 工程 | 内容 |
| --- | --- |
| ファームウェアを選択 | 出力対象と利用可能な機能を決定します。 |
| 基本設定 | ファームウェア側の名前とUSB識別情報を確認します。 |
| 詳細設定 | Bootmagic、Vial UID、ZMK固有設定などを対象別に設定します。RMKでは省略されます。 |
| キーマップ | レイヤーとキーアクションを編集します。 |
| ライティング | QMK/VIAまたはVialでRGB Matrixの配置を編集します。 |
| Macro / Combo / Tap Dance | 対応する振る舞いの定義を編集します。RMKでは表示されません。 |
| {ファーム名}出力 | 検証結果を確認し、対象ファームウェアのソースを保存します。 |

ファームウェアを切り替えても、別ターゲット向けに入力済みの設定はプロジェクト内に保持されます。選択中のボードまたはMCUが対象ファームウェアに非対応の場合は、選択画面と出力画面にハードウェア警告が表示されます。

## 右側の編集パネル

選択中の工程に合わせてキーマップ設定、ライティング、Macro、Combo、Tap Danceなどのタブが表示されます。「レイアウトオプション」はキーマップからも開けます。

詳しい操作は[キーマップ編集](/design/keymap)、[ファームウェア対応表](/reference/firmware-compatibility)、[アクション / キーコード](/reference/actions)を参照してください。ハードウェア側の工程は[ハードウェア設計ワークフロー](/design/)で説明します。
