# マトリクス編集

マトリクス編集では、各キーの row / col と、ファームウェア出力に使う row / col ピンを確認します。見た目の並びと配線上の行列は一致しないことがあるため、Smiðr では物理レイアウトと同じキャンバス上で対応関係を見ながら整理できます。

## row / col の考え方

row と col は、ファームウェアがキーを識別するためのマトリクス座標です。たとえば `row: 2, col: 5` のキーは、スキャン行列の 2 行目、5 列目にあるキーとして扱われます。

物理レイアウト上の上下左右と、配線上の row / col は必ずしも一致しません。左右分割、親指キー、縦にずれたカラムなどでは、見た目よりも配線やファームウェア側の定義を優先して整理します。

## 割り当ての確認

割り当て済みのキーはキャンバス上に行列情報が表示されます。未設定や重複がある場合は、QMK / VIA / Vial / ZMK 向けの出力前にマトリクス編集で確認します。

row / col が未設定のキーは、キーマップやファームウェア出力で正しく参照できません。レイアウトを大きく変更したあとや、KLE / VIA / Vial 由来のデータを読み込んだあとには、この画面で行列の対応を見直すと安全です。

## row / col を割り当てる

`ペイントモード` では、現在の row / col を指定してからキャンバス上のキーをクリックし、そのキーへ行列座標を割り当てます。クリックするたびに次の row / col へ進めたい場合は、自動インクリメントの方向を選びます。

`手動入力` では、選択したキーに対して row / col を直接入力します。特定のキーだけを直したいときや、読み込んだデータの一部を確認しながら修正したいときに使います。

`自動割り当て (左→右)` は、現在のレイアウトに対して row / col をまとめて割り当てます。最初の下書きとして使い、そのあと実際の配線に合わせて必要なキーを調整すると効率的です。

`すべての割り当てをクリア` は、キーに設定された row / col を消去します。ピン設定は消えないため、行列座標だけを作り直したいときに使います。

## row / col ピン

下部のピン設定パネルでは、`行ピン` と `列ピン` を設定します。ここで設定した順番が、ファームウェアに出力される行・列ピンの順番になります。

ピンはタグとして表示されます。入力欄に `GP0` のようなピン名を入力して追加するか、右側のピン候補からクリックして追加します。タグの左側に表示される番号は、そのピンが row / col 配列の何番目かを表します。

タグは削除でき、ドラッグして順番を入れ替えられます。配線図や `matrix_pins` の順番と合わない場合は、ピン名そのものだけでなく並び順も確認してください。

## ピン候補から割り当てる

右側には、ハードウェア設定で選んだ開発ボードまたは MCU の使用可能なピン候補が表示されます。

`行ピン`、`列ピン`、または `特殊ピン` の入力欄を選択してから候補ピンをクリックすると、その対象へ割り当てられます。入力欄を選んでいない状態では、候補ピンは選択先がないため割り当てられません。

`重複割り当てを防止` が有効な場合、すでに使われているピンは別の対象へ割り当てられません。同じ GPIO を意図的に使う特殊な構成では、この設定を切り替えて確認します。

候補にないピン名を使う場合は、`カスタムピン指定` に直接ピン名を入れて割り当てます。手入力した値は、そのままピン名として扱われるため、選択している MCU やファームウェアで使える表記か確認してください。

## 分割キーボード

分割キーボードを有効にしている場合は、左手側と右手側の row / col ピンを別々に設定できます。

左手側は `左側 行ピン` / `左側 列ピン`、右手側は `右側 行ピン` / `右側 列ピン` として表示されます。左右で同じ配線を使う設計か、左右それぞれに異なるピン配列を持つ設計かに合わせて設定します。

分割通信に使うピンは、特殊ピンの `シリアル TX ピン` として設定します。row / col ピンとは役割が違うため、行列のピン数には含まれません。

## 特殊ピン

RGB、OLED、エンコーダ、分割キーボードなどの機能を有効にしている場合は、対応する特殊ピン欄が表示されます。

- `RGBデータ`: RGB LED のデータピンです。
- `I2C SDA` / `I2C SCL`: OLED などの I2C デバイスに使うピンです。
- `エンコーダ A` / `エンコーダ B`: エンコーダの A / B ピンです。
- `シリアル TX ピン`: 分割キーボードのシリアル通信に使うピンです。

これらはキーの row / col ではなく、ファームウェア機能に使う追加のピンです。エクスポート先によって必要な設定名は変わりますが、Smiðr では同じ画面でまとめて管理できます。

## すべて消去

`すべてのピンをクリア` は、row / col ピンと特殊ピンの割り当てをまとめて消去します。配線を最初から作り直すときに使います。

キーの配置やキーマップそのものを消す操作ではありません。ただし、ファームウェア出力に必要なピン情報は空になるため、消去後は row / col ピンと必要な特殊ピンを設定し直してください。
