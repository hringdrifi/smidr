# マトリクス編集

ハードウェア工程の「マトリクス」では、各キーをファームウェア上のスイッチ位置へ対応付けます。通常マトリクスではrow / col、ダイレクト配線ではコントローラーのピンを割り当てます。

## 通常マトリクス

row / colは物理的な上下左右ではなく配線上の座標です。キーに指定できる範囲は、ピン設定で用意した行・列の数に対応します。未設定、範囲外、重複があるとファームウェア出力の検証で問題になります。

ペイントモードでは現在のrow / colを選んでキーをクリックします。列または行の自動インクリメントを使うと連続して割り当てられます。単一キーは手動入力でも修正できます。「自動割り当て」は物理的な並び順から初期値を作るため、実際の配線に合わせて確認してください。

## ダイレクト配線

ダイレクト配線では各キーが個別のGPIOを使用します。通常マトリクスのrow / colは使いません。分割時はキーのsideと左右それぞれのピン配列からファームウェア上の位置を決定します。

## ピンは「ピン設定」で編集

行・列ピン、ダイレクトピン、LED、I2C、エンコーダー、分割通信のピンは左工程ナビゲーションの「ピン設定」で編集します。「マトリクス」画面はキー単位の対応付けに集中します。

マトリクス配線の表示を有効にすると、同じrowまたはcolに属するキーの関係をキャンバス上で確認できます。レイアウト変更後や外部JSONの読み込み後は、出力前に割り当てを見直してください。
