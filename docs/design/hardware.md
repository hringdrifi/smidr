# ハードウェア設定

ハードウェア設定では、キーボード名、USB 識別情報、コントローラー、ダイオード方向、QMK / Vial 向けの詳細設定、ファームウェア機能を設定します。

ここで設定した内容は、QMK / VIA / Vial / ZMK 向けに書き出すファイルへ反映されます。レイアウトやキーマップが正しくても、ハードウェア設定が実機と合っていないと、生成したファームウェアや JSON が期待通りに動かないことがあります。

## 識別情報と USB

`キーボード名` と `製造元` は、生成するプロジェクトやファームウェア側の識別情報として使われます。QMK / Vial / ZMK 向けの出力では、キーボード名やメーカー名として反映されます。

`VID` と `PID` は USB デバイスの識別子です。VIA / Vial 対応キーボードでは、ホスト側がキーボードを識別するためにも使われます。既存のキーボードを再現する場合は、そのキーボードの値に合わせます。新しく作る場合は、他の製品やプロジェクトと衝突しない値を使ってください。

## コントローラーの指定

`コントローラーの指定方法` では、開発ボードとして指定するか、MCU として指定するかを選びます。

`開発ボード` を選ぶと、Pro Micro、Elite-C、nice!nano などのボード名を使って設定します。QMK / Vial 向けの出力では `development_board` として扱われ、ZMK 向けの出力ではビルド対象の board として使われます。

`MCU` を選ぶと、RP2040 や ATmega32U4 などのマイコン名を直接指定します。QMK / Vial 向けの出力では、processor や bootloader の設定に反映されます。

開発ボードとして使っている場合は、基本的には `開発ボード` を選ぶ方が分かりやすいです。基板上に独自実装した MCU を使う場合や、ボード名より processor を直接指定したい場合は `MCU` を選びます。

## 対応ファームウェア

コントローラーの候補には、`[QMK]`、`[ZMK]`、`[QMK/ZMK]` のような対応バッジが表示されます。

- `[QMK]`: QMK / Vial 系のソース出力で使える候補です。
- `[ZMK]`: ZMK ソース出力で使える候補です。
- `[QMK/ZMK]`: 両方の出力で使える候補です。

出力したいファームウェアに対応していないコントローラーを選ぶと、生成できるファイルやビルド方法が制限されることがあります。

## ダイオード方向

`ダイオード方向` は、キーマトリクスのスキャン方向を指定します。QMK / Vial / ZMK の設定では、一般的に `COL2ROW` または `ROW2COL` として扱われます。

この値は、実際の配線でダイオードがどちら向きに入っているかに合わせます。間違っていると、キーが反応しない、意図しないキーが入力される、マトリクスが正しく読めないといった問題につながります。

row / col ピンそのものは、マトリクス編集のピン設定パネルで設定します。ハードウェア設定では、コントローラーやダイオード方向など、出力全体に関わる条件を確認します。

## QMK 詳細

`MATRIX_MASKED` は、行ピンと列ピンで同じ GPIO を共有するような特殊な配線を QMK / Vial ソース出力に反映するための設定です。通常の配線では無効のままで構いません。

行ピンと列ピンが重複していて `MATRIX_MASKED` が無効の場合、警告が表示されます。GPIO の共有を意図している場合だけ有効にしてください。

`BOOTMAGIC` は、QMK / Vial の Bootmagic に使うキー位置を指定します。Bootmagic を有効にすると、起動時に特定のキーを押して設定変更やリセット系の操作を行えるようになります。

Bootmagic の行・列は、マトリクス編集で設定した row / col を基準に指定します。

## ファームウェア機能

`ファームウェア機能` では、出力に含めたい機能を切り替えます。

- `RGB ライト`: RGB LED の設定やデータピンを使う場合に有効にします。
- `エンコーダー`: ロータリーエンコーダを使う場合に有効にします。
- `OLED`: OLED などの I2C デバイスを使う場合に有効にします。
- `VIA サポート`: VIA 対応の出力を行う場合に有効にします。
- `分割キーボード`: 左右分割キーボードとして扱う場合に有効にします。

有効にした機能に応じて、マトリクス編集のピン設定パネルに RGB、I2C、エンコーダ、分割通信用の特殊ピン欄が表示されます。

## Vial 設定

Vial 向けに出力する場合は、`Vial UID` と `ロック解除コンボ` を確認します。

`Vial UID` は、Vial がキーボードを識別するための 8 バイトの値です。別のキーボードと重複しない値を使う必要があります。`IDを生成` を使うと、新しい UID を作成できます。

`ロック解除コンボ` は、Vial で書き込み操作を許可するために押す 2 つのキー位置です。`VIAL_UNLOCK_COMBO_ROWS` / `VIAL_UNLOCK_COMBO_COLS` として出力されます。

指定する値は、キーの物理位置ではなくマトリクス上の row / col です。マトリクス編集で割り当てた行・列と対応しているか確認してください。

## 開発者向け設定

`デバッグモード` を有効にすると、パーサーや操作の詳細ログがコンソールに表示されます。通常の設計やリマップでは無効のままで構いません。

読み込んだ JSON の解析や、エクスポート結果の調査、開発中の問題確認をしたい場合に使います。
