# ハードウェア設定

ハードウェア工程では、ファームウェアや基板データが参照する共通の物理情報を設定します。新規プロジェクトを作成すると、最初に基本設定モーダルが開きます。

## 基本設定

キーボード名、製造元、VID/PID、開発ボードまたはMCU、ダイオード方向を設定します。コントローラー候補には対応ファームウェアが表示され、後で選ぶファームウェアとの組み合わせを判断できます。

マトリクス方式は通常のrow/colとダイレクト配線から選びます。分割キーボードでは左右の配線と通信方式も共通ハードウェア設定として扱います。

## ピン設定

ピン設定はヘッダーとフッターを固定したモーダルで、中央の設定領域をスクロールできます。通常マトリクスでは行ピンと列ピン、ダイレクト配線ではキーごとの候補となるピンを設定します。

LED、OLED/I2C、エンコーダー、分割通信などは、必要なピンが有効に設定されると機能も有効になります。使用済みピンは候補から除外され、マトリクス、ダイレクトピン、周辺機能間の重複を防ぎます。

## 分割通信

分割キーボードでは最初に有線または無線を選びます。有線では半二重と全二重を選択します。

- 半二重は共用TX/RXピンを1本使用します。
- 全二重はTXとRXを別々に割り当て、左TXと右RX、左RXと右TXを接続します。
- 無線ではUARTピンを表示・予約しません。

ファームウェアごとの生成条件があります。QMK/Vialの無線分割とZMKの単線半二重は出力できません。RMKの無線分割はnRF52、有線分割はRP2040 PIOが対象です。詳細なエラーはファームウェア出力時に表示されます。

## ファームウェア固有設定

Bootmagic、Vial UIDと解除位置、ZMKの設定などはハードウェア工程ではなく、ファームウェア工程の「詳細設定」で編集します。別ファームウェアへ切り替えても入力済みの値は保持されます。

## 基板出力

「基板出力」ではスイッチ、ダイオード、LEDなどのフットプリントを選び、KiCad用データを生成します。ファームウェアソースはここではなく、ファームウェア工程の最後から出力します。
