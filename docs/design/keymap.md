# キーマップ編集

キーマップでは、現在のレイヤーを選び、選択中のキーにキーコードを割り当てます。通常キーだけでなく、透過、無効、Momentary、Toggle、Layer Tap、Mod Tap などのアクションも扱います。

## キーコードの割り当て

キーを選択してから、下部のキーコードパネルで割り当てたいアクションを選びます。Smiðr 内部では QMK / ZMK の違いを直接文字列で扱うのではなく、共通のアクションとして保持します。

## キーパレット

`キーパレット` は、よく使うキーコードを一覧から選んで割り当てるためのパネルです。キャンバス上でキーを選択すると、パレット内のキーコードをクリックして現在のレイヤーへ割り当てられます。

パレットは `基本`、`ISO/JIS`、`レイヤー`、`メディア`、`マクロ`、`特殊` などのタブに分かれています。英数字や記号は `基本`、JIS 配列で使うキーは `ISO/JIS`、レイヤー移動や透過キーなどは `レイヤー` や `特殊` から選びます。

複数のキーを選択している場合は、同じキーコードをまとめて割り当てられます。片手側の修飾キーや、同じ動作にしたい親指キーなどをまとめて設定するときに使います。

## キーマップ設定

`キーマップ設定` は、選択中のキーに割り当てるアクションを細かく調整するためのパネルです。単純なタップキーだけでなく、レイヤー操作やホールド時の動作を持つキーを設定できます。

`アクションタイプ` では、タップキー、モッドタップ、レイヤー一時切り替え、レイヤートグル、レイヤー置換、レイヤータップ、Any などを選びます。タイプを切り替えると、対象レイヤー、修飾キー、タップ時のキーコードなど、必要な入力欄が表示されます。

たとえば、親指キーをタップで Space、ホールドでレイヤー 1 にする場合は `レイヤータップ` を使います。タップで文字を入力し、ホールドで Control や Shift として使う場合は `モッドタップ` を使います。

`Any` は、Smiðr の標準アクションでは表しきれないキーコードやファームウェア固有の表記を直接扱いたい場合に使います。通常のキーやレイヤー操作は、できるだけパレットやアクションタイプから選ぶと、QMK / VIA / Vial / ZMK 向けの出力で扱いやすくなります。

アクションタイプやキーコードの内部表現を詳しく確認したい場合は、[アクション / キーコード](/reference/actions) を参照してください。
