# ハードウェア設計ワークフロー

ハードウェア工程では、キーボードの基本情報、配線、物理レイアウト、マトリクスを順に設計し、最後に基板データを出力します。各工程は左側の工程ナビゲーションから移動できます。

## 工程

| 工程 | 内容 |
| --- | --- |
| 基本設定 | プロジェクト名、USB識別情報、ボードまたはMCU、ダイオード方向、配線方式を設定します。 |
| ピン設定 | 行・列、ダイレクト配線、LED、I2C、エンコーダー、分割通信のピンを設定します。 |
| レイアウト | キーの位置、形状、回転、レイアウトオプションを編集します。 |
| マトリクス | 各キーへマトリクス座標またはダイレクトピンを割り当てます。 |
| 基板出力 | KiCad用の回路図・PCBデータを書き出します。 |

基本設定とピン設定はモーダルで開きます。入力内容はその場でプロジェクトへ反映され、Xボタン、背景クリック、Escで閉じても保持されます。

## 右側の編集パネル

選択中の工程に合わせてキープロパティやマトリクスペインターなどのタブが表示されます。「レイアウトオプション」はレイアウトとマトリクスから開ける共通タブです。

詳しい操作は[ハードウェア設定](/design/hardware)、[レイアウト編集](/design/layout)、[マトリクス編集](/design/matrix)を参照してください。ファームウェア側の工程は[ファームウェア設計ワークフロー](/design/firmware)で説明します。
