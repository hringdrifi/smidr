# 設計モード

設計モードは、キーボードそのものを作るための作業場所です。中央のキャンバスでキーを直接編集し、周辺のパネルで追加操作や詳細設定を行います。

## レイアウト / マトリクス / キーマップ

| エディタ | 用途 |
| --- | --- |
| レイアウト | キーの位置、サイズ、回転、レイアウトオプションを編集します。 |
| マトリクス | 各キーに row / col を割り当てます。 |
| キーマップ | レイヤーごとのキーコード、モッドタップ、レイヤータップなどを編集します。 |

## プロジェクトを作る

上部の新規ボタンから空のプロジェクトを作成し、必要に応じてプリセットを読み込みます。既存の KLE / VIA / Vial / QMK JSON から始めることもできます。
