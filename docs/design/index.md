# Design モード

Design モードは、キーボードそのものを作るための作業場所です。中央のキャンバスでキーを直接編集し、周辺のパネルで追加操作や詳細設定を行います。

## Layout / Matrix / Keymap

| エディタ | 用途 |
| --- | --- |
| Layout | キーの位置、サイズ、回転、レイアウトオプションを編集します。 |
| Matrix | 各キーにマトリックスの row / col を割り当てます。 |
| Keymap | レイヤーごとのキーコード、モッドタップ、レイヤータップなどを編集します。 |

## プロジェクトを作る

上部の新規ボタンから空のプロジェクトを作成し、必要に応じてプリセットを読み込みます。既存の KLE / VIA / Vial / QMK JSON から始めることもできます。
