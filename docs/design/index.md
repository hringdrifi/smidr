# 設計ワークフロー

プロジェクトの設計作業は「ハードウェア」と「ファームウェア」に分かれています。どちらも左側の工程ナビゲーションから移動でき、工程末尾に出力があります。

## ハードウェア工程

| 工程 | 内容 |
| --- | --- |
| 基本設定 | プロジェクト名、USB識別情報、ボードまたはMCU、ダイオード方向、配線方式を設定します。 |
| ピン設定 | 行・列、ダイレクト配線、LED、I2C、エンコーダー、分割通信のピンを設定します。 |
| レイアウト | キーの位置、形状、回転、レイアウトオプションを編集します。 |
| マトリクス | 各キーへマトリクス座標またはダイレクトピンを割り当てます。 |
| 基板出力 | KiCad用の回路図・PCBデータを書き出します。 |

基本設定とピン設定はモーダルで開きます。入力内容はその場でプロジェクトへ反映され、Xボタン、背景クリック、Escで閉じても保持されます。

## ファームウェア工程

最初にQMK/VIA、Vial、ZMK、RMKから対象を選択します。選択後は対象に応じて工程が組み替わり、非対応のキーや機能はパレットから除外されます。

| 工程 | 内容 |
| --- | --- |
| ファームウェアを選択 | 出力対象と利用可能な機能を決定します。 |
| 基本設定 | ファームウェア側の名前とUSB識別情報を確認します。 |
| 詳細設定 | Bootmagic、Vial UID、ZMK固有設定などを対象別に設定します。RMKでは省略されます。 |
| キーマップ | レイヤーとキーアクションを編集します。 |
| ライティング | QMK/VIAまたはVialでRGB Matrixの配置を編集します。 |
| Macro / Combo / Tap Dance | 対応する振る舞いの定義を編集します。RMKでは表示されません。 |
| {ファーム名}出力 | 検証結果を確認し、対象ファームウェアのソースを保存します。 |

ファームウェアを切り替えても、別ターゲット向けに入力済みの設定はプロジェクト内に保持されます。選択中のボードまたはMCUが対象ファームウェアに非対応の場合は、選択画面と出力画面にハードウェア警告が表示されます。

## 右側の編集パネル

選択中の工程に合わせてキープロパティ、マトリクスペインター、キーマップ設定、Macroなどのタブが表示されます。「レイアウトオプション」は複数の工程から開ける共通タブです。

詳しい操作は[ハードウェア設定](/design/hardware)、[レイアウト編集](/design/layout)、[マトリクス編集](/design/matrix)、[キーマップ編集](/design/keymap)を参照してください。
