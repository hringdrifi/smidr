# 用語集

## Selection

現在操作対象になっているキーの集合です。

## Focus

回転の中心やプロパティ編集の基準になるキーです。

## Anchor

Shift クリックによる範囲選択の起点です。

## Pivot

キーや選択範囲を回転するときの基準点です。

## Layer

同じ物理キーに別の割り当てを持たせるための面です。

## Physical Key

レイアウト上の1つのスイッチ位置を表すキーです。位置、寸法、回転、マトリクス上の接続先、バックライト種別などの物理的な情報を持ちます。

## Visual Layout

キーマップやキーコードパレットに表示するキートップ表記の配列です。QWERTY、JIS、AZERTYなどを選べますが、キーコードやエクスポート内容は変わりません。

## Keymap

各レイヤーの各キー位置へアクションを割り当てた表です。物理レイアウトとマトリクスの対応を基に、ファームウェアや接続中の機器へ反映されます。

## Keycode

キー入力や機能を表すコードです。通常の文字キー、修飾キー、メディアキー、ライティング操作などを含みます。

## Action

キーを押したときに実行する動作です。単一キーの入力、レイヤー切り替え、マクロ呼び出しなどを表します。

## UniversalAction

Smiðr 内部でファームウェアに依存せずアクションを表す共通形式です。出力時や実機への書き込み時に、QMK/VIA、Vial、ZMK、RMK向けの表現へ変換されます。

## UniversalKey

通常キー、機能キー、メディアキーなどをファームウェア非依存で表す共通のキー定義です。通常は `tap` アクションから参照します。

## Transparent

現在のレイヤーで割り当てを持たず、下位レイヤーの割り当てを使用する設定です。`trans` アクションとして表します。

## Layer Tap

短く押すと指定したアクションを実行し、押し続けると指定したレイヤーを有効にするアクションです。`lt` とも表記します。

## Mod Tap

短く押すと指定したアクションを実行し、押し続けると修飾キーとして働くアクションです。`mt` とも表記します。

## Macro

複数のキー操作をまとめて実行する定義、またはその定義を呼び出すアクションです。設計モードの定義と、実機で編集するDynamic Macroは別に管理されます。

## Combo

複数のキーを同時に押したときに、別のアクションを実行する定義です。

## Tap Dance

キーのタップ回数や押し方に応じて異なるアクションを実行する定義です。SmiðrではTap、Hold、Double Tap、Tap Holdの4スロットとTapping Termで扱います。

## Behavior

ZMKでキーの動作を定義するノードです。ZMK Studioのリマップでは、機器にあらかじめ存在するbehaviorを割り当てられますが、新しい定義の追加にはソース出力と再ビルドが必要です。

## Dynamic Macro / Combo / Tap Dance

Vialなどの対応機器に保存され、実機リマップ画面から直接編集できる定義です。Smiðrプロジェクトの設計用定義やソース出力とは分けて扱います。

## Matrix

行（row）と列（column）の交点でキーを識別する配線方式です。キーごとに行・列を割り当て、ファームウェアが押下位置を検出します。

## Direct Input

各キーを個別のGPIOへ直接接続する方式です。行・列のマトリクスを使用しません。

## Layout Option

分割Backspaceやスペースバーの構成など、選択に応じて表示・使用するキーを切り替えるレイアウトの選択肢です。

## Layout Input Unit

レイアウト編集時の座標と寸法の入力単位です。`u`（キー単位）または`mm`（ミリメートル）を選択できます。

## Firmware Target

出力先として選択するファームウェアの種類です。QMK/VIA、Vial、ZMK、RMKから選び、利用可能なアクション、設定工程、出力内容が切り替わります。

## QMK

カスタムキーボード向けのオープンソースファームウェアです。SmiðrはQMKソースと、VIA対応のキーマップを出力できます。

## VIA

対応キーボードのキーマップを、再ビルドなしで変更するための仕組みです。実機リマップではDynamic Keymapとして表現できるキーコードを扱います。

## Vial

QMKを基盤に、Dynamic Macro、Combo、Tap Danceなどの実機編集機能を提供する仕組みです。

## ZMK

主に無線対応の自作キーボードで使われる、Zephyrベースのファームウェアです。キー動作はbehaviorを組み合わせて定義します。

## ZMK Studio

ZMK対応機器のキーマップなどを接続して編集する仕組みです。USBではWeb Serial、デスクトップ版ではBLE接続を利用できます。

## RMK

Rustで実装されたキーボードファームウェアです。SmiðrはRMK向けの設定ファイル一式をZIPで出力できます。

## Remap Mode

VIA、Vial、ZMK Studio対応キーボードへ接続し、ファームウェアを再ビルドせずに現在の設定を編集するモードです。変更は接続中の機器へ直接書き込まれます。

## Capability

接続中の機器が公開する、利用可能な機能の情報です。対応していないキーやDynamic機能は、リマップ画面で表示されないか無効になります。

## Preview Pattern

ドラッグや回転などの連続操作中は一時的なプレビュー状態だけを更新し、操作の確定時に履歴へ1回だけ記録する更新方式です。

## Undo / Redo

直前の編集を取り消す操作と、取り消した編集をやり直す操作です。標準ショートカットはそれぞれCtrl / Cmd + Z、Ctrl / Cmd + Yです。

## .smidr Project

Smiðrのプロジェクトファイル形式です。レイアウト、ハードウェア、ファームウェアなどの設計情報を保存します。Visual Layoutのようなユーザー環境設定は保存しません。
